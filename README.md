# RACE — Anime Vehicle Toy

An interactive web toy where you choose an anime vehicle and race it to the finish.

## 🎮 Live Demo

[Play RACE](https://devayanichathurya.github.io/anime-vehicle/)

## 📌 About

RACE is a small interactive racing experience inspired by iconic anime vehicles.

The project focuses on simple controls, visual interaction, animation, and a responsive design rather than complex game mechanics.

## 🚗 Vehicles

- **AKIRA (1988)** — Kaneda's Bike
- **REDLINE (2009)** — Trans Am 20000

## ✨ Features

- Interactive vehicle selection
- Keyboard controls
- On-screen controls for mobile
- Animated racing track
- Speed counter
- Race progress bar
- Background colour transformation during the race
- Boost interaction
- Race completion screen
- Responsive layout

## 🎮 Controls

### Keyboard
- `←` Move left
- `→` Move forward
- `Space` Activate Boost

### Mobile
Use the on-screen buttons to control the vehicle.

## 🛠️ Built With

- HTML
- CSS
- JavaScript

No external frameworks or libraries are required.

## ▶️ Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Click **START** and begin the race.

## 🎯 Project Goal

The goal of this project was to create a small, creative, and interactive web toy using basic frontend technologies while focusing on user interaction and visual polish.
